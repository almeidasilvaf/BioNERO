# Orthogroups between maize and rice

The orthogroups were downloaded from the PLAZA 4.0 Monocots database.

## Usage

``` r
data(og.zma.osa)
```

## Format

A 3-column data frame with orthogroups, species IDs and gene IDs.

## References

Van Bel, M., Diels, T., Vancaester, E., Kreft, L., Botzki, A., Van de
Peer, Y., ... & Vandepoele, K. (2018). PLAZA 4.0: an integrative
resource for functional, evolutionary and comparative plant genomics.
Nucleic acids research, 46(D1), D1190-D1196.

## Examples

``` r
data(og.zma.osa)
```
