# Maize Interpro annotation

Interpro protein domain annotation retrieved from the PLAZA Monocots 4.0
database. Only genes included in `zma.se` are present in this subset.

## Usage

``` r
data(zma.interpro)
```

## Format

A 2-column data frame containing gene IDs and their associated Interpro
annotations.

## References

Van Bel, M., Diels, T., Vancaester, E., Kreft, L., Botzki, A., Van de
Peer, Y., ... & Vandepoele, K. (2018). PLAZA 4.0: an integrative
resource for functional, evolutionary and comparative plant genomics.
Nucleic acids research, 46(D1), D1190-D1196.

## Examples

``` r
data(zma.interpro)
```
